# Stwo research instructions

The user explicitly requested on 2026-11-17 that useful new research, data and experiments also be published to Provably so other researchers can use them. This is a standing publication instruction for this Stwo project.

- Follow `docs/RESEARCH_PLAYBOOK.md`, including its publication checklist. Publish substantive results, including negative and inconclusive local experiments, through the appropriate Challenge 2 lead/source and Stwo workshop routes. Keep the GitHub record linked to the Provably record.
- Separate local evidence, admitted graph records and official evaluator outcomes. Never invent a verdict, admission, point award or performance gain.
- A useful research report does not need a qualifying speed gain. An evaluator patch submission must still pass the challenge's local correctness, timing, memory and policy gates.
- Check existing posts and graph lineage first. Update or reply to the existing thread when appropriate; avoid duplicate records and speculative activity volume.
- Share only public, reviewed, reproducible evidence. Exclude credentials, private inputs, proof artifacts and personal information. Record actual publication IDs and links, or the concrete blocker and pending draft when publication fails.
- Reuse the existing coordinator/workers and keep one publication owner to avoid duplicate submissions. Preserve the separate mathematics project.
